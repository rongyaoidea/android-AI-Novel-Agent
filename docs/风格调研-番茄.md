# 番茄小说写作风格调研（含预设蒸馏）

> 调研日期：2026-10-15 ｜ 方法：公开网络检索（21 次中文检索，来源见文末）＋ 官方榜单/研讨会评语交叉核对
> 用途：为「写作风格预设」功能提供依据。**结论按「可执行」优先**：能写进提示词规则的量化约束 > 泛泛的修辞形容词。
> 免责：作者文风为基于公开访谈/书评/榜单的**推断归纳**，非逐句统计；产品内的预设以「风格类型」命名，不以作者名命名（规避版权与模仿风险）。

## 一、平台硬约束（可直接写成提示词参数）

| 维度 | 结论 | 备注 |
|---|---|---|
| 商业模式 | 免费阅读 + 广告分成，作者 55% | 收益及格线 = 日更 4000 字 |
| 单章字数 | **2050–2300 字**（听书场景友好） | 单章 2000 字 × 2 章/天是最经济结构 |
| 分发漏斗 | 2 万字可签约 → 8 万字进入 7 天验证期 → 首秀流量池 PK（总留存 = 流量 × 点击率 × 章节完读） | 断更直接掉推荐 |
| 关键指标 | **追读率 > 完读率**；平路超过 3 章追读开始掉 | 后台只给「三日追更」 |
| 黄金三章 | 第 1 章：冲突 + 金手指 + 章末反转钩，**不交代世界观**；第 2 章：打脸名场面 + 埋长期伏笔；第 3 章：亮出全书核心契约 | 前 300 字抛核心冲突 |
| 前 1 万字 | 人物名字 ≤5 个；不写童年；不做大跨度时间跳跃 | |
| 章末钩子 | 三类：动作截断 / 疑问绑定主角命运 / 延后释放；**每 2–3 章一个高能钩子**，连续 5 章强钩子会让读者麻木；「谜语人式空钩」= 消耗信任 | 编辑专门盯每章最后三行 |
| 爽点节奏 | 每章 ≥1 小爽点；每 3–5 章 1 中爽点；每卷 1 大爽点；**平均 1.8 章一次情绪高峰**（追读 top10% 特征） | |
| 读者画像 | 月活 2.6 亿，下沉市场 >51%，男女比 57:43；**听书为主** | |
| AI 味治理 | 平台已专项治理：不会数数（说四个字下段写五个字）、重点错位（埋伏笔不回收）、段落等长/节奏匀速、下一章无交代改剧情 | 这是反向约束清单 |

### 通用节奏基线（所有预设共用）
1. 单章 2000 字级，前 300 字内出冲突或悬念，不写世界观铺垫
2. 每章 ≥1 个爽点/信息爆点；平路连续 ≤3 章
3. 章末最后三行必须有钩（动作截断/疑问绑定/信息投放），禁空谜语
4. 段落长短交错、事件密度有快慢——**段落等长 + 匀速是 AI 味头号特征**
5. 回忆杀 ≤300 字且与当前剧情强相关；不写童年
6. 同一情绪形容词禁跨场景重复（「头皮发麻/浑身发冷/空气凝固」列入黑名单）
7. 视角纪律：全书固定人称，同一段内不跳视角

## 二、男频代表作者文风拆解（节选要点）

|---|---|---|
| 杀虫队队员 | 《十日终焉》 | 越肩第三人称**严格限知**；每章 1 个谜题环节 + 至少 1 个未解事实；推理后必跟反证；无金手指面板；同一形容词禁跨副本复用；章末信息投放/身份反转 |
| 三九音域 | 《我在精神病院学斩神》 | 战斗 6–15 字短句连打 / 抒情 20–40 字排比；抒情 ≤25%；每卷一个配角独立高光；台词要「可截图」；新名词首现配人话解释 |
| 一月九十秋 | 《诸神愚戏》 | 智斗：推理链必须双向显式；短句 + 机锋对白；每 800–1200 字一次比喻式吐槽；章末推翻本章「安全结论」 |
| 六个葫芦 | 《时停起手，邪神也得给我跪下！》 | 金手指规则**可算账**（次数/叠加/冷却写清，全书一致）；章末「规则升级」钩；危机 4 : 反杀 4 : 日常 2 |
| 紫灵风雪 | 《长生烬》 | 苟道日常：每章可 0 战斗但必须有「时间流逝感」细节；战斗 ≤15% 一笔带过；章末「不经意反差」钩；**长线禁止丢主线** |
| 徐二家的猫 | 《从前有座镇妖关》 | 群像：配角可先于主角成神；短句 + 省略号收尾；悲壮 4 : 热血 3 : 痞气幽默 3；章末立场反转 |
| 夜来风雨声丶 | 《诡舍》 | 规则怪谈：副本制（20–40 章），章节标题带【副本名】前缀；规则以告示/日记文本块插入；章末「有人违规但不说谁」；反例：恐怖词库反复用、主角零风险破局 |

## 三、女频代表作者文风拆解（节选要点）

| 作者 | 代表作 | 文风要点（可执行） |
|---|---|---|
| 任欢游 | 《缚春情》 | 古雅克制；**章名 2 字为主**、章名即钩子；器物/节令/称谓考据密度高；情绪不直说（写合乎礼法的反常举动）；男主是变量不是答案；反派不降智 |
| 烽火尽染 | 《登金阙》 | 权谋双强、事业线驱动；允许慢热但每章一次博弈；「大女主必须在制度层面兑现」（半醒不醒的大女主会被差评） |
| 尤宫羽 | 《坤仪》 | 宫斗攻心：对话必有第二层意思；男非女洁、互相攻心；男主是被攻略对象而非救世主；女主清醒不恋爱脑 |
| 山外 | 《长矛老师》 | 发疯毒舌：对话占比高、金句独立成段；发疯必须解构真实行业现象；爽点全在公共场合（便于短剧改编） |
| 猫不秃 | 《游戏入侵》 | 无 CP 大女主：第一章主动改写原设；每条机缘配明确增量；每 10 章一次称号解锁；女性角色 ≥2/3 且各有事业线；禁雌竞；反派不降智 |
| 小盐子 | 《蓄意逐风》 | 发癫人设 + 恋综穿书；夸张内心独白；场面失控钩；发癫必须服务人设 |
| 信仰之名R | 《婚途升职》 | 年代技术流：技术细节参数化；强强联合不依附；章末「硬核成果」钩 |

### 女频横向规律
- 女频 ≠ 言情：两条主线 = ① 无 CP 大女主爽文（新人友好）② 强暧昧拉扯恋爱文（卖拉扯感，不写平淡甜宠）
- **去油**：不再写霸道总裁式物质铺张宠爱，要「落到实处」的细腻日常互动
- 男主「苏感」= 把古早言情梗合理化的天赋；道德洁癖型男主长期有效
- 追妻火葬场底线：前期男主不得突破读者底线（否则变「劝分」）
- 标题即承诺：标题承诺什么必须兑现

## 五、雷点清单（写进所有预设的反例兜底）

| 类别 | 雷点 |
|---|---|
| 男频第一雷区 | 绿帽 / 送女 / 女主背叛（即使后文解释是假的，读者已走） |
| 挫折禁忌 | 「出人意料的挫折」（已预告的成功突然失败）；主角可以败，不能耻辱地败 |
| 金手指 | 规则前后矛盾、忽强忽弱（番茄差评第一来源） |
| 套路疲劳 | 退婚→打脸→升级三件套连轴转 |
| 注水 | 一章塞满发呆/吃饭/走路等无效内容 |
| 对话 | 角色像背课文、背着「你好我好大家好」的客套 |
| 视角 | 一段内跳视角、人称混用 |
| 专业硬伤 | 年代文出现晚出的作物/词汇；行业文写成过家家 |
| 大女主专属 | 「半醒不醒」（喊口号不兑现）；雌竞 |
| 追妻火葬场 | 前期男主突破底线 → 读者持续劝分 |
| AI 味 | 数字不一致、埋伏笔不回收、段落等长、节奏匀速、无交代改剧情 |
