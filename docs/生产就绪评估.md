# 生产就绪评估（android-AI-Novel-Agent）

> 评估日期：2026-10-15 ｜ 对应版本：0.4.0（提交见仓库 main）｜ 方法：代码审查 + 全量测试 + CI 证据 + 本地真机式冒烟
> 结论口径：**分场景**判断，不笼统说「能/不能投产」。

---

## 0. 结论速览

| 场景 | 是否具备 | 说明 |
|---|---|---|
| 个人日常自用 | ✅ **具备** | 功能闭环完整；数据安全三件套（备份/令牌/Key 加密）齐备；崩溃有启动自愈；发布可复现 |
| 小范围内测（朋友装 APK） | ✅ **基本具备** | 需补 1 项稳定性（LLM 重试）与 1 项 Android 14 后台策略确认 |
| 应用商店公开上架 | ⚠️ **尚不具备** | 缺：隐私政策、正式图标、cleartext 白名单收紧、armeabi-v7a、（可选）反馈渠道 |
| 商业化运营/多用户 | ❌ **差距较大** | 无账号体系、无多端同步、无内容合规过滤、无成本上限 |

---

## 1. 功能完整度（对「一个人写完一本书」的闭环）——强

已实现且经过测试的完整链路：**开书 → 立项 → 章节规划（可按阶段确认）→ 正文（流式）→ 审校 → 选段修文/续写/重写 → 角色与伏笔台账（自动抽取+上下文注入）→ 书籍体检 → 导出 TXT → 备份/恢复 → 用量统计 → 文风预设（10 套）→ 提示词模板可编辑**。

明确不做（避免误判）：拆书/RAG、EPUB、多卷、TTS、漫画/短剧、多人协作。

## 2. 稳定性

| 项 | 现状 | 评级 |
|---|---|---|
| 断点续跑 | 运行记录 + 已完成章节跳过，中断后「继续创作」可续 | ✅ |
| 进程中断恢复 | **本轮新增**：启动时把孤儿 `running` 运行标记为 failed（带可读原因），否则会永久卡住「已有运行进行中」的互斥判定 | ✅（已修） |
| 数据自愈 | 章节重排的负索引占位在启动时自动修复 | ✅ |
| LLM 调用容错 | 仅 `stream_options` 400 时回退重试；**网络抖动 / 429 / 5xx 无重试退避** → 一次抖动会中断整次运行（可手动续跑，不丢已完成章节） | ⚠️ P0 |
| 运行互斥 | 同书同时只允许一个 run；不同书可并行；SQLite `busy_timeout=5000` 兜底 | ✅ |
| 超长任务 × Android | 前台服务（`dataSync`）+ `START_STICKY`；无 WakeLock；**Android 14+ 对 dataSync 类型有 6 小时/24 小时窗口限制**（超时触发 onTimeout 必须停止），长会话需处理 | ⚠️ P0（需真机实测确认） |
| 输入防护 | 选段 ≤4000 字、续写前文截 1500 字、恢复包 ≤256MB；编辑/结构操作有运行中保护 | ✅ |

## 3. 数据安全

| 项 | 现状 | 评级 |
|---|---|---|
| 本地访问令牌 | `/api/*` 需 `x-ainovel-token` / `?token=`（常量时间比较）；health 与静态放行 | ✅ |
| API Key 加密 | AES-256-GCM；密钥由 Android Keystore 主密钥包裹（不可导出）；换密钥自动置空提示重填 | ✅ |
| 备份/恢复 | `VACUUM INTO` 一致性快照 → zip；恢复校验（zip 结构/可打开/含 novels 表）后进程内覆盖；非法包 400 | ✅ |
| 落盘明文 | 作品正文本身为明文 SQLite（本地文件，Android 沙箱内）——如需防 root 提取属另一等级需求 | 可接受 |
| 备份包加密 | ❌ 备份 zip 为明文（换机传输时注意渠道） | P2 |
| 恢复的 schema 守卫 | 依赖启动迁移（ensure_column）兜底，无版本号硬校验 | P2 |

## 4. 性能与容量

| 项 | 现状 | 评级 |
|---|---|---|
| 流式体验 | SSE 按 ~80 字分片推送，边写边看 | ✅ |
| DB | SQLite WAL、必备索引、单连接 Mutex（低并发够用） | ✅ |
| 大书风险 | **章节列表接口每次返回全部章节的全文**（字数/预览在服务端算），300 章以上书籍响应体与 WebView 内存压力上升；未做分页 | ⚠️ P1 |
| 生成吞吐 | 串行为主（章与章之间顺序），符合叙事依赖；单书内无并行需求 | ✅ |

## 5. 可观测性

| 项 | 现状 | 评级 |
|---|---|---|
| 桌面日志 | stdout（`tracing`），可用 `RUST_LOG` 调级 | ✅ |
| Android 日志 | **本轮新增**：引擎日志写入 `filesDir/ainovel.log`（每次启动截断、ANSI 关闭），排障可导出 | ✅（已修） |
| 用量/成本可见 | 按任务/章节记账（输入/输出/缓存命中/未命中），未知口径显示「—」 | ✅ |
| 崩溃上报 | 无（隐私取向，可接受）；无「导出日志」入口 | P2 |

## 6. 平台合规与分发

| 项 | 现状 | 评级 |
|---|---|---|
| 签名 | 固定 keystore（Secrets 长期复用），可覆盖升级 | ✅ |
| 分发链路 | CI 一键：测试 → 交叉编译 → 签名 APK → artifact / Release 附件 | ✅ |
| ABI 覆盖 | 仅 `arm64-v8a`（近 8 年主流机型；不含 32 位与 x86 模拟器） | ⚠️ P1 |
| cleartext | 全局 `usesCleartextTraffic=true`（实为回环服务，但配置口径偏松） | ⚠️ P1 |
| 商店材料 | 无隐私政策 / 正式图标 / 屏幕截图素材 | P1（上架才需要） |
| minSdk | 29（Android 10+，覆盖绝大多数在用设备） | ✅ |

## 8. 投产前最小清单（按优先级）

**P0（建议 1–2 天内完成）**
1. LLM 调用重试与退避：网络错误 / 429 / 5xx 自动重试 2–3 次（指数退避 + 抖动），失败才中断本次运行——直接决定「能不能稳定跑完一本书」。
2. Android 14+ `dataSync` 前台服务时长策略：真机长会话验证；准备「被系统停止后自动续跑」或调整服务类型的方案。

**P1（内测期间）**
3. 大书性能：章节列表分页或返回瘦身（去掉全文，仅保留预览与字数）。
4. `networkSecurityConfig` 白名单（仅 127.0.0.1）+ 增加 `armeabi-v7a`（可选）。
5. 用量预算上限（每月 token 上限，超限暂停并提示）——防意外烧钱。
6. 上架材料：隐私政策、正式图标、商店截图（仅公开上架需要）。

**P2（体验/增强）**
7. 备份包可选密码加密；恢复的 schema 版本号硬校验。
8. 「导出日志」入口（Android 设置页）。
9. EPUB 导出、模型路由（规划/正文/审校分模型）、TTS 听书。

---

## 9. 本轮评估驱动的修复（已随版本发布）

1. **孤儿运行自愈**：`Db::open` 启动时把 `running` 运行标记为 `failed`（附可读原因），修复「进程被杀后永久卡住创作入口」的问题；新增单元测试。
2. **Android 引擎文件日志**：JNI 启动时初始化 `filesDir/ainovel.log`（截断 + info 级），此前 Android 端引擎日志完全不可见。
